# 红中 · 家庭牌桌

无需 GPT、ChatGPT 或 GitHub 账号即可使用的静态网页小助手。

## 功能

- 手牌录入、红中万能牌、自摸成胡和听牌结构检查
- 弃牌后听牌提示，以及副露和杠牌录入
- 四人自摸、奖码和杠的自动积分，预览确认、撤销上一局和两枚骰子
- 适配电脑和手机浏览器

## 使用与数据

直接打开 GitHub Pages 网页即可使用。也可以下载此仓库后打开 `index.html`，或在本目录运行 `python -m http.server 8765` 后访问 `http://localhost:8765`。

应用不依赖第三方脚本、GPT API、登录服务或后端。手牌、昵称和积分只保存在当前浏览器的本地存储中，应用不会上传这些内容；不同设备之间不会自动同步。网页托管服务仍可能记录普通网页访问日志。

## 规则边界

默认牌集为万、筒、条各 1～9 和四张红中。仅检查四副面子加一对将，红中可替代任意牌，七对等地方规则未启用。听牌表示再自摸一张后的结构成立，未扣除对手手牌或牌河。弃牌提示不是胜率建议，请以你们确认的地方规则为准。

积分仅作娱乐记录，不涉及货币、投注或付款。

## 自动积分

输入基数、谁自摸、奖码数和四家杠次数，先预览明细再确认记账。

- 每位其他玩家的自摸分：`-基数 × (1 + 奖码数)`；自摸者收三份
- 每个杠从另外三家各收一个基数；各家的杠分分别叠加
- 奖码和杠次数空白默认 0；0 码仍有一份底分
- 基数支持 0.01～100000、最多两位小数，内部以百分之一分整数精确计算
- 奖码数为 0～100，各家杠次数为 0～4
- 确认记账后保留基数，自摸者、奖码和杠次数重置；可撤销上一局
- 兼容原有本机的旧版手动积分记录

## 部署

GitHub 仓库设置 → Pages → Deploy from a branch → `main` → `/ (root)`。根目录的 `.nojekyll` 文件让静态资源直接发布。

## 文件

- `index.html`：页面结构
- `style.css`：样式
- `engine.js`：麻将结构和积分计算
- `app.js`：界面与本地保存
