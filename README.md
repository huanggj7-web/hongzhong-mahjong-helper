# 红中 · 家庭牌桌

无需 GPT、ChatGPT 或 GitHub 账号即可使用的麻将手牌和娱乐积分小助手。

入口：https://huanggj7-web.github.io/hongzhong-mahjong-helper/

## 功能

- 连续点选录入手牌，摸一张、打一张、撤销操作，保留本机手牌
- 红中万能牌、自摸成胡和听牌结构检查，副露和杠牌录入
- 未听牌时比较向听数与理论有效进牌；14 张时按牌效率排列弃牌候选
- 自摸、奖码和杠的自动积分，明细预览、确认记账和撤销上一局
- 同桌共享房间：开桌人记账，其他人打开相同链接看分
- 适配电脑和手机浏览器

## 同桌共享记分

1. 在“四人积分”点击“开共享房间”
2. 复制房间看分链接，分享给同桌
3. 开桌人输入本局参数，预览并确认记账；其他人自动看到云端确认后的积分

看分链接不包含开桌权限。只有开桌时的同一浏览器可记账、改名和撤销；开桌权限保存在该浏览器，清除浏览器数据后无法恢复。知道房间链接的人可看分，请只分享给同桌。

共享房间的昵称、积分及操作记录保存在 OpenAI Sites 云端数据库。每个房间 30 天后到期，最多 1000 次记账、撤销或改名操作。断网或云端未确认时暂停共享记账，避免误计和重复提交。

## 使用与数据

手牌、本机昵称和本机积分只保存在当前浏览器，不会自动上传或并入共享房间。不同设备的本机记录不会同步。只有主动开桌并使用共享记分时，房间昵称和积分才会传到云端。网页托管服务可能记录普通访问日志。

前端无第三方脚本、GPT API 或登录依赖。共享服务使用公开 API，但写入操作只接受开桌浏览器签名；前端代码不包含服务器密钥。

本机模式也可以下载仓库后，在本目录运行 `python -m http.server 8765`，访问 `http://localhost:8765`。手牌后台分析需要通过网站或本地 HTTP 打开；共享房间请使用上面的正式入口。

## 自动积分

- 每位其他玩家的自摸分：`-基数 × (1 + 奖码数)`；自摸者收三份
- 每个杠从另外三家各收一个基数，各家的杠分分别叠加
- 奖码和杠次数空白默认 0；0 码仍有一份底分
- 基数支持 0.01～100000、最多两位小数，内部以百分之一分整数计算
- 奖码数为 0～100，各家杠次数为 0～4
- 确认记账后保留基数，自摸者、奖码和杠次数重置；可撤销上一局
- 本机模式兼容原有旧版手动积分记录

## 规则与分析边界

默认牌集为万、筒、条各 1～9 和四张红中。仅检查四副面子加一对将，红中可替代任意牌，七对等地方规则未启用。

向听越低，离标准胡牌越近；同向听优先比较理论有效枚数，再比较种类。理论枚数扣除当前手牌、副露和本次建议弃牌，不含未知对手牌、牌河与牌墙，也未跟踪过往弃牌。排序是结构数学比较，不是整局绝对最优或胜率保证。

积分仅作娱乐记录，不涉及货币、投注或付款。

## 部署

GitHub Pages 使用 `main` 分支根目录，`.nojekyll` 让静态资源直接发布。页面和后台分析器引用带版本号的资源，避免浏览器混用旧缓存。

本仓库仅包含公开前端。共享房间服务部署在 `https://hongzhong-family-table.huanggj7.chatgpt.site`，只允许正式 GitHub Pages 来源的浏览器访问。

## 文件

- `app.js`：手牌和本机记分
